# Общий дашборд показаний счётчиков

Одна страница — все счётчики. Программа собирает показания воды, электричества и газа в одном месте и позволяет подать их одной кнопкой.

## Как это работает

Этот портал — главный экран, который объединяет два других:
- **Вода и электричество** — берёт данные у портала [ikus.pesc.ru](https://github.com/hram/pesc)
- **Газ** — берёт данные у портала [Петербургрегионгаз](https://github.com/hram/peterburgregiongaz)

Поэтому сначала нужно установить и запустить оба этих портала, и только потом этот.

## Что нужно для установки

- Оба портала установлены и запущены:
  - pesc работает на `http://localhost:8003`
  - газ работает на `http://localhost:8004`
- Python 3.10 или новее

## Установка

**1. Скачайте программу**

```bash
git clone https://github.com/hram/meters.git
cd meters
```

**2. Установите зависимости**

```bash
pip install -e ".[dev]"
```

**3. Создайте файл настроек**

```bash
cp .env.example .env
```

Файл `.env` уже содержит правильные значения по умолчанию. Менять их нужно только если порталы запущены на других адресах:

```
PESC_API_URL=http://localhost:8003
GAZ_API_URL=http://localhost:8004
```

## Запуск

```bash
uvicorn portal.main:app --port 8005
```

Откройте браузер: **http://localhost:8005**

> Убедитесь что перед запуском уже работают оба портала (pesc на 8003 и газ на 8004).

## Как пользоваться

На главной странице три колонки: **Вода**, **Электричество**, **Газ**.

В каждой колонке:
- Текущие показания счётчика
- Поле для ввода нового показания
- Кнопка **Подать показания** — отправляет только этот сервис

Вверху страницы:
- Кнопка **Подать все показания** — отправляет все три сервиса одновременно

Если один из порталов недоступен — его колонка покажет ошибку, остальные продолжат работать.

## Автоматическая подача

В каждой карточке есть тумблер **Авто**. Когда он включён, программа каждый день в 12:00 по московскому времени проверяет: если сегодня с 15 по 21 число и рабочий день — подаёт последние известные показания.

Изменить время можно в `.env`:

```
SCHEDULER_HOUR=10
SCHEDULER_MINUTE=30
```

**Журнал** всех автоматических подач доступен по ссылке в правом верхнем углу страницы.

> **Важно:** если автоподача включена здесь, отключите её в отдельных порталах (pesc и газ) — иначе показания будут подаваться дважды.

> **Важно:** компьютер должен быть включён в момент автоподачи.
